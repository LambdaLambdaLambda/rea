# Ocean Sort

A small offline browser game where players sort ocean wildlife and human-made litter into the correct categories.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:4173.

## Test

```bash
npm test
```

## Notes

- No backend, login, or network access is required.
- Local best scores save in the browser if storage is available.
- The game is intentionally self-contained and fully offline.
