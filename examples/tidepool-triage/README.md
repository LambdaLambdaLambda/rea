# Tidepool Triage

A small, original ocean-themed sorting game. Decide whether each item belongs
to nature or is human-made litter, then see how your choices add up.

## Run locally

Open `index.html` in a modern browser. The game has no build step, dependencies,
account, or network requests.

## Play

Choose **Nature** or **Litter** for each item. Use the on-screen buttons, or
press `1` for Nature and `2` for Litter. The game gives a short explanation for
each answer and can be replayed at the end.
